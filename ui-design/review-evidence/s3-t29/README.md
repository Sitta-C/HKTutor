# Floating tutor comparison screenshots

Captured on 2026-11-07 from the running HKTutor web client and its real local API, using public
tutor listings in the local demo database. These are application screenshots, not design mockups
or intercepted API fixtures. Capturing them did not create or modify business records.

- `selection-desktop.png` — 1440 × 1000; three tutors selected and the Notebook Ledger button.
- `comparison-desktop.png` — 1440 × 1000; immediate Course Tabs comparison of three tutors.
- `comparison-mobile.png` — 430 × 932; two-tutor comparison at a mobile viewport.

The screenshots show the guest view and public tutor information only. Empty ratings and future
availability reflect the actual demo data at capture time. Middle-dot separators are removed from
the generated UI and accessible labels; ordinary punctuation in stored user content is preserved.
