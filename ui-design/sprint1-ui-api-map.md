# HKTutor Sprint 1 UI and API map

All paths use the global `/api/v1` prefix. APIs marked **Proposed** still need a final Swagger
contract from Backend.

Detailed input, output, validation, and error requirements are in
[`sprint1-api-field-requirements.md`](./sprint1-api-field-requirements.md).

| API                                                                          | Page use                                      | API task ID                      | Page task ID             | What does it do                                                                                                |
| ---------------------------------------------------------------------------- | --------------------------------------------- | -------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `POST /auth/register`                                                        | `/register`                                   | S1-T08 (Done)                    | S1-T06, S1-T11 (Done)    | Creates a Student or Tutor account and records privacy consent.                                                |
| `POST /auth/verify-email`                                                    | `/register/verify`                            | S1-T08 (Done)                    | S1-T06, S1-T09 (Done)    | Verifies the email token and signs the user in.                                                                |
| `POST /auth/resend-verification`                                             | `/register/verify`                            | S1-T08 (Done)                    | S1-T06, S1-T09 (Done)    | Sends a replacement verification email.                                                                        |
| `POST /auth/login`                                                           | `/`                                           | S1-T08 (Done)                    | S1-T06, S1-T09 (Done)    | Signs the user in and returns the authenticated user and access token.                                         |
| `POST /auth/refresh`                                                         | All authenticated pages                       | S1-T08 (Done)                    | S1-T09 (Done)            | Restores and rotates the signed-in session when the web app loads.                                             |
| `POST /auth/logout`                                                          | `/dashboard` and all authenticated pages      | S1-T08 (Done)                    | S1-T09 (Done)            | Revokes the refresh session and signs the user out.                                                            |
| `GET /auth/me`                                                               | `/dashboard` and all authenticated pages      | S1-T08 (Done)                    | S1-T09 (Done)            | Returns the current user's identity and role. The endpoint exists but the current web client does not use it.  |
| **Proposed** `GET /tutors/me/profile`                                        | `/dashboard/profile`, Tutor `/dashboard`      | S1-T15 (In Progress)             | S1-T16 (To do)           | Loads the tutor's profile, verification state, rating, and review count.                                       |
| **Proposed** `PUT /tutors/me/profile`                                        | `/dashboard/profile`                          | S1-T15 (In Progress)             | S1-T16 (To do)           | Creates or updates the authenticated tutor's basic profile.                                                    |
| **Proposed** `GET /tutors/me/listings`                                       | `/dashboard/listings`, Tutor `/dashboard`     | S1-T15 (In Progress)             | S1-T16 (To do)           | Lists the tutor's draft, published, and archived teaching listings.                                            |
| **Proposed** `GET /tutors/me/listings/:listingId`                            | `/dashboard/listings/[listingId]/edit`        | S1-T15 (In Progress)             | S1-T16 (To do)           | Loads one owned listing into the edit form.                                                                    |
| **Proposed** `POST /tutors/me/listings`                                      | `/dashboard/listings/new`                     | S1-T15 (In Progress)             | S1-T16 (To do)           | Creates a teaching listing as a draft.                                                                         |
| **Proposed** `PUT /tutors/me/listings/:listingId`                            | `/dashboard/listings/[listingId]/edit`        | S1-T15 (In Progress)             | S1-T16 (To do)           | Updates the subject, grade, price, and description of an owned listing.                                        |
| **Proposed** `PATCH /tutors/me/listings/:listingId/status`                   | `/dashboard/listings`, listing edit page      | S1-T15 (In Progress)             | S1-T16 (To do)           | Publishes or archives an owned listing after validation.                                                       |
| **Proposed** `GET /catalogs/subjects`                                        | Listing form, `/tutors` search                | S1-T15, S1-T21                   | S1-T16, S1-T22           | Returns active subjects for form and filter options.                                                           |
| **Proposed** `GET /catalogs/grade-levels`                                    | Listing form, `/tutors` search                | S1-T15, S1-T21                   | S1-T16, S1-T22           | Returns active grade levels in display order.                                                                  |
| **Proposed** `GET /availability/me?from=…&to=…`                              | `/dashboard/availability`, Tutor `/dashboard` | S1-T18 (In Progress)             | S1-T19 (To do)           | Lists the tutor's availability in a date range; the page displays it in Bangkok time.                          |
| **Proposed** `POST /availability/me`                                         | `/dashboard/availability`                     | S1-T18 (In Progress)             | S1-T19 (To do)           | Creates an availability slot and rejects invalid or overlapping time ranges.                                   |
| **Proposed** `DELETE /availability/me/:slotId`                               | `/dashboard/availability`                     | S1-T18 (In Progress)             | S1-T19 (To do)           | Deletes an owned open slot and rejects deletion when the slot is reserved.                                     |
| **Proposed** `GET /tutors?subjectId=…&gradeLevelId=…&maxPrice=…&minRating=…` | `/tutors`                                     | S1-T21 (To do)                   | S1-T22 (To do)           | Searches only verified tutors with published listings using the selected filters.                              |
| **Proposed** `GET /tutors/:tutorProfileId`                                   | `/tutors/[tutorProfileId]`                    | S1-T21 (To do)                   | S1-T22 (To do)           | Loads a public tutor profile, matching listings, rating, and review summary.                                   |
| **Proposed** `GET /tutors/:tutorProfileId/availability?from=…&to=…`          | Tutor detail and booking slot picker          | S1-T18 (In Progress)             | S1-T22, S1-T25 (To do)   | Lists the tutor's future open slots without exposing private booking data.                                     |
| `POST /bookings`                                                             | `/dashboard/bookings/new`                     | S1-T24 (In Progress)             | S1-T25 (To do)           | Creates a pending booking transaction and prevents two students from booking the same slot.                    |
| **Proposed** booking quote endpoint                                          | `/dashboard/bookings/new`                     | Not assigned; required by S1-T25 | S1-T25 (To do)           | Returns the selected tutor, listing, slot, currency, subtotal, discount, and final amount before confirmation. |
| **Proposed** `GET /bookings/me`                                              | Student `/dashboard`, `/dashboard/bookings`   | Not assigned; required by S1-T25 | S1-T25, S1-T26 (To do)   | Lists the student's bookings for dashboard summary and booking history.                                        |
| **Proposed** `GET /bookings/me/:bookingId`                                   | `/dashboard/bookings/[bookingId]`             | Not assigned; required by S1-T25 | S1-T25 (To do)           | Loads the submitted booking, status, lesson time, tutor, listing, and amount snapshot.                         |
| **Proposed** tutor booking-list endpoint                                     | Tutor `/dashboard`                            | Not assigned                     | S1-T25, S1-T26 (To do)   | Lists incoming bookings needed by the Tutor dashboard.                                                         |
| No runtime API                                                               | `/privacy`                                    | —                                | S1-T11 (Done)            | Displays the privacy notice bundled with the web application.                                                  |
| No runtime API                                                               | `/about-me`                                   | —                                | Outside Sprint 1 backlog | Displays static project information.                                                                           |
| No Sprint 1 domain API                                                       | Admin `/dashboard`                            | —                                | S1-T09 (Done)            | Displays the authenticated Admin placeholder until an admin workflow is defined.                               |
