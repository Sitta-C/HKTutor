# HKTutor Sprint 1 UI and API map

This table uses the real `/api/v1` application prefix. All task IDs follow the
[Trello Sprint 1 board](https://trello.com/b/5rez0fNO/hktutor-sprint-1-backlog), checked and aligned
on 2026-09-09. Implementation state was rechecked against `main` and local `design/ui` at `de95d0b` on
2026-09-10. **Code conflict** means the controller exists, but its current runtime path does not
match the agreed contract. **Proposed** means no matching controller exists in this codebase yet.

Detailed input, output, validation, authorization, and UI impact are in
[`sprint1-api-field-requirements.md`](./sprint1-api-field-requirements.md).
